# Molefy

Учёт расходов на $mol и Гипер Базе: кольцо расходов, счета, переводы, валюты с ручными курсами, бюджет, повторы.

- `bog/molefy/app` приложение
- `bog/molefy/book` счета, категории, операции и остатки
- `bog/molefy/restore` восстановление без дублей
- `bog/molefy/csv` чтение и выгрузка CSV
- `bog/molefy/sqlite` чтение резервной копии `.db` без wasm
- `bog/molefy/ring`, `calc`, `entry`, `settings`, `login`, `icon` части интерфейса

Вход через Гипер ID или свой ключ. Данные лежат в отдельном зашифрованном ленде.
